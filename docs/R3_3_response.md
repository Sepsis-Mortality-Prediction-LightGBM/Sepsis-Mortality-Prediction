# Reviewer 3, Comment 3

> The statement "Data are available from the corresponding author upon request" is not compliant with PhysioNet data sharing policies for MIMIC-IV and eICU-derived datasets, as PhysioNet-certified data explicitly prohibits secondary redistribution by individual users. The correct wording should be revised to "All raw clinical datasets can be accessed via PhysioNet after completion of required CITI training". Full code sharing via a public GitHub repository is also required to support full analytical reproducibility. Given that cohort inclusion and feature extraction rules directly determine all reported results, the full patient screening code and feature engineering code must be made publicly available.

## Response

We thank the reviewer for emphasizing both the PhysioNet access requirements and the need to disclose the complete computational workflow. We agree that access to MIMIC-IV and eICU-CRD should be obtained through PhysioNet rather than through redistribution of patient-level data by the authors.

We have assembled an accompanying reproducibility package, Supplementary_Code_R3_3_v0.2.zip. It contains the machine-learning analysis and figure-generation code, reconstructed cohort-screening SQL for both databases, extraction SQL and definitions for all 22 predictors, the six SOFA component rules, dependency specifications, and a README documenting the workflow and its limitations. We have also added scripts to compare future source exports with the archived cleaned cohorts at the levels of sample size, sequential screening results, patient identifiers, outcomes, variable distributions, missingness and individual predictor/component values. An explicit Yes/No-to-0/1 treatment-encoding correction is documented separately; no updated model performance is claimed before the affected analyses are rerun.

We distinguish code availability from validation of the reconstructed extraction. The SQL files are explicitly labelled “not validated against the actual source databases.” Offline syntax, schema-reference and score-rule checks have been completed, but the reconstructed SQL has not been executed against the actual MIMIC-IV or eICU-CRD source releases. We therefore do not claim to have reproduced the original patient selection, extracted values or cohort sizes. The supplied aggregate reference profiles describe the existing cleaned files and are not newly extracted source data.

The database-access wording supplied with this revision identifies MIMIC-IV version 2.2 (https://physionet.org/content/mimiciv/2.2/) and eICU-CRD version 2.0 (https://physionet.org/content/eicu-crd/2.0/), as specified in the manuscript, and states that access requires individual credentialing, the required training and the applicable data-use agreement. The actual source-release versions remain to be confirmed from the original extraction records.

The code archive is prepared for public GitHub release; the public repository deposit and URL have not yet been finalized, and we do not describe a local archive as a completed public release. Thus, the code-preparation and offline verification work is complete, while public deposition and source-database extraction validation remain outstanding. Any discrepancies identified during source validation will be documented and resolved before the reconstructed workflow is described as reproducing the original extraction.
