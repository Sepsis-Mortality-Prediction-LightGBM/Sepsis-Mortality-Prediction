# Data and Code Availability — wording supported by the current package

MIMIC-IV (version 2.2) is available through PhysioNet at https://physionet.org/content/mimiciv/2.2/, and the eICU Collaborative Research Database (version 2.0) is available at https://physionet.org/content/eicu-crd/2.0/. Access requires individual credentialing, completion of the required training and acceptance of the applicable data-use agreement. Patient-level data from these resources are not redistributed in the accompanying code package. The stated versions follow the manuscript and should be confirmed from the original extraction records.

The analysis code, reconstructed extraction SQL, variable definitions, SOFA rules, environment specifications and validation scripts are supplied in Supplementary_Code_R3_3_v0.2.zip. The reconstructed SQL has not been validated against the actual source databases. A public GitHub deposit has not yet been finalized; no public repository URL or code DOI is claimed. The institutional cohort is not included in this code package and requires a separate institution-approved availability statement.
